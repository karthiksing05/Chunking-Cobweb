# TRELLIS (Chunking Cobweb)

Work with Dr. Pat Langley and Dr. Chris MacLellan (ISLE internship) on a computational account of cognitive chunking backed by Cobweb concept formation. Every element of an experience is both a **concept** (a category of things that behave alike) and a **chunk** (a whole made of parts).

## TRELLIS v2

TRELLIS v2 keeps concepts and chunks in two Cobweb hierarchies: the **representation hierarchy** (how elements behave) and the **composition hierarchy** (what they are made of). It reads one probabilistic grammar off them by minimum description length, and learns from analysed experiences or from experiences alone, by day and by night. The two hierarchies are the core of v2: every other part is read off them or feeds them.

The same machinery runs on sentences, on Chinese characters (components placed by spatial operators), and on chess positions, whose parts are joined by typed relations (the directions of a queen's rays and a knight's jumps) instead of left-to-right order.

## Data

None of the data is committed. Each domain's loader says how to fetch its data.

| Domain | Source | Licence | Location |
|---|---|---|---|
| Synthetic grammars (the paper's corpora) | generated by `scripts/` | – | `../trellis_v1/data`, or `data/cfg_*` |
| Simple English | TinyStories (Eldan & Li 2023), validation file | CDLA-Sharing-1.0 | `data/tinystories` |
| Children's books | Project Gutenberg: McGuffey readers, Aesop, Grimm, Alice, Oz | public domain in the US | `data/gutenberg`, `data/attention` |
| Penn Treebank sample | NLTK | non-commercial use | `data/ptb_sample` |
| Chinese characters | CJKVI IDS (based on CHISE) | GPL | `data/ids` |
| Chess | Lichess database, January 2013 | CC0 | `data/chess` |

## Quick start

```
python -m pytest tests/trellis2 -q                       # needs cobweb_cu (docs/FRAMEWORK.md, section 13)
python experiments/v2/run_synthetic.py --out experiments/v2/results/main
python experiments/v2/run_unsupervised.py --seeds 13,17
```

Every experiment, with its running time, is listed in [`docs/FRAMEWORK.md`](docs/FRAMEWORK.md), section 13.
